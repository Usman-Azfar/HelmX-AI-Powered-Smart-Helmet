# Figures

Figures are separated from numeric results so reviewers can browse the visual evidence quickly.

| Directory | Contents |
|---|---|
| `foundational/` | Early benchmark, latency, replay, quantization, resource, and robustness plots |
| `live-sensor/` | Physical MPU live-sensor, soak, motion, timing, and trigger-path plots |
| `final-closure/` | Review figures for corrected A-B-A acquisition, class fidelity, scheduler pairs, timing distributions, and high-range benign motion |

Where a figure has an associated table or machine-readable dataset, that evidence is retained under
`results/`. Figures should be interpreted with the caveats in
[the complete results report](../results/COMPLETE_RESULTS.md).

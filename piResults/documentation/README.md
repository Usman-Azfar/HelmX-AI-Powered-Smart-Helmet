# Research Documentation

This directory contains supporting material rather than primary result data.

| Directory | Contents |
|---|---|
| `protocols/` | Acquisition, review, publication, and IEEE Sensors test procedures/checklists |
| `historical-reports/` | Earlier chronological reports retained for traceability |
| `status/` | Validation progress and closure-status records |

Historical documents may describe findings later corrected or superseded. The authoritative public
interpretation is the [complete results report](../results/COMPLETE_RESULTS.md), which explicitly
labels superseded evidence and unperformed tests.
